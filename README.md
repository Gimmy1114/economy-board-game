# 經濟棋局 · 併購派對

3D 骰子派對棋盤遊戲。2–8 位玩家可在同一台電腦輪流遊玩，也可用 5 碼房間代碼跨頁籤／跨裝置連線。擲骰、踩格、抽道具、放技能、買星、併購，最後把整座棋盤收進口袋。

直接開啟 [index.html](./index.html) 即可單機遊玩；多人與遠端連線請用 `node serve.mjs` 啟動本機伺服器。

## 遊戲模式

| 模式 | 勝利條件 | 特色 |
| --- | --- | --- |
| 🌟 企業之星 | 先拿 3 顆星；或季末星數最高 | 經過或停留在出發格都能買星，星價 500 起，全場每賣 1 顆 +500，可付「星價 + 300」強買對手的星 |
| 💰 首富競爭 | 總資產率先達到 8,000 | 季數過半通膨 ×2，倒數兩季 ×4，資產與踩格收益同步放大 |
| 💀 邪惡企業 | 成為唯一倖存者；季末比較生還季數 | 每 5 季毀滅日雷射收保護費（初始 1,000，每次收取後漲價，由首富開始），付不出來化為藍色罷工幽靈 |
| 🎲 隨機模式 | 依抽到的模式 | 開局從企業之星、首富競爭、邪惡企業隨機抽一種，並套用固定預設數值 |

三種模式的季數、勝利星數、總資產目標、保護費間隔與初始保護費，都在「開啟測試（單機沙盒）」旁依模式顯示並鎖定；隨機模式全部鎖定，固定為企業之星 10 季／3 星、首富競爭 24 季／8,000、邪惡企業 20 季／首期保護費 1,000。

建立對局畫面與多人房間大廳另有可摺疊的「進階設定」面板，房主可調整回合計時、初始資產、黑市、幽靈、內線交易、併吞價格、自動回能及自訂地圖。設定會存入對局狀態並由房主透過 PeerJS 同步給客機；只有按下自訂地圖「確認」才會改用配置格數，否則照常生成隨機地圖。驅鬼設定會同時扣除指定資產與技能能量；黑市可揭露道具、調整價格並以 25% 機率出現不提供道具的爛貨。支援回合計時的多人房間倒數，自動回能於玩家回合開始補充 1 點（上限 9）。

罷工幽靈進入憤怒狀態時，命中玩家會將資產驅鬼費加倍，能量費維持設定值，接著強制往回移動 3 格並結算落點；回退期間以紅色光暈標示棋子，結算完成前不能結束回合。

幽靈的驅鬼費提示顯示在幽靈圖示上，會依目前進階設定動態格式化金額；格子自己的說明只顯示該格效果。

新對局的開場介紹與倒數播放期間會暫時隱藏罷工幽靈；倒數結束後才顯示棋盤幽靈。

遊戲彈窗遮罩會置於幽靈圖層上方；黑市、投資、查稅與內線交易等強制決策不顯示右上角關閉按鈕，須透過視窗選項完成。

最終結算視窗的遮罩也會覆蓋棋盤幽靈；結算視窗只保留底部操作按鈕，並置中排列。

單機最終結算的「關閉」按鈕使用專屬置中容器，不受共用結算頁尾的左右分散排版影響；多人結算確認按鈕維持原有配置。

進階設定改用單欄橫向排列，標籤文字保持單行，數字輸入框限制寬度並避免內容超出面板。

進階設定中的「自訂地圖」可調整 48 格的空白、一般效果與特殊格數量；不足 48 格時會自動補成空白格。內線交易格數量另計，固定出發格也不計入 48 格合計。按「確認」套用自訂地圖；按「關閉自訂」則回到隨機地圖。

企業之星與首富競爭若第一名平手，會進入驟死賽：憤怒幽靈移動 ×1.5、扣款 ×2。

## 玩法

1. 選擇 2–8 位玩家與企業角色，再依模式設定季數上限與勝利條件。每位玩家初始總資產 1,200、技能能量 1 點。
2. 每回合開始自動抽 1 個道具（普通與神話共用 3 格）；滿了必須先丟棄才能取得新道具。擲骰前可自由使用道具或發動企業技能；技能每次消耗 1 點能量。
3. 擲出單顆六面骰（1–6），棋子逐格前進。經過或停留在起點領 200 總資產；企業之星模式還會彈出買星視窗。
4. 骰子停下、棋子完全靜止後才會結算格子效果、觸發互動視窗或幽靈事件。
5. 格子效果：
   - **藍色發財格**：獲得 300 總資產。
   - **紅色蕭條格**：扣除 150 營運費。
   - **黃色技能格**：補充 1 點技能能量（上限 9）。
   - **綠色事件格**：立刻抽一張即時事件。
   - **罷工幽靈**：只有「踩在幽靈格」才觸發，扣 1,000 總資產並隨機沒收 1 個道具。幽靈格是灰色斜線格，滑鼠移上去可看效果；幽靈每次結束回合隨機移動 1–3 格。
6. 停在普通格後抽一張「二選一」快速決策，共有六種情境，選項會即時生效。
7. 停在出發格或經過出發格時，企業之星可購買星星；先拿到目標星數的人立刻獲勝。
8. 總資產達 2,000 可併購一位對手，讓對方成為子公司；子公司每回合上繳 40% 收益，存到 1,000 可花 1,000 獨立反撲。
9. 所有玩家完成行動後結算一季；到達季數上限時依模式比較排名。

## 道具與企業技能

五種普通道具各有 20% 抽取機率：🛡️ 買保險、🎲 123 骰子、🎲 456 骰子、🔄 移形換位、📈 開槓桿。道具欄旁有 🗑️ 可直接丟棄。

🌐 弱者的領域以藍色框線標示在棋盤上；對手進入時會出現明顯的扣款標籤、震動特效與專屬音效。

十種企業各有專屬技能：炎上商法、計畫性報廢、購物節狂歡、惡意做空、垃圾食物成癮、幽靈派單、凍結帳戶、強制徵收、碳稅制裁、零日漏洞。大廳另可選「未定新創集團 🎲」，開局隨機分配企業。完整數值與說明請看遊戲內「規則說明」。

## 多人連線

### 手機操作與回合倒數

- 手機對局採橫向模式；直向時會顯示「請將手機轉為橫向遊玩」遮罩。橫向畫面左右各半：左側地圖、右側玩家操作。左側可用右上角按鈕縮放及拖曳地圖；縮放只改格子版面尺寸，不改字體、圖示或棋子大小，縮到整張地圖可見時不能再拖曳。
- 左側地圖底部顯示最新一則動態，點擊後可查看完整動態清單，再按 × 返回地圖。地圖預設放大並置中目前回合玩家所在格；轉向或調整視窗大小時，罷工幽靈會依所在格重新定位，玩家棋子則隨格子版面自動排列。
- 手機右側操作區上方顯示回合標籤、可點擊查看規則的模式圖示、目前季數／季數上限、玩家名稱與總資產／模式指標／技能能量；名稱會依可用寬度縮小，必要時以省略號收尾。動作與道具上方保留玩家狀態列，不含地圖四色記號。
- 手機右側動作列固定擲骰按鈕，其他動作可左右滑動；技能按鈕只顯示技能名稱。下方三個道具格等寬橘框，垃圾桶長條可切換丟棄模式；選取道具後會先確認，取消模式可再點一次垃圾桶列。
- 手機右側底部提供「玩家與子公司」、「規則說明」與「退出遊戲」選單。前兩者會以可垂直捲動面板覆蓋操作區，按「退出／返回」回到操作畫面；退出遊戲會先確認，再返回首頁並保留對局。
- 全螢幕切換可在支援的瀏覽器鎖定橫向；部分 iPhone 瀏覽器不支援網頁 Fullscreen API，可使用 Safari 的「加入主畫面」以全螢幕開啟。
- 多人回合按下擲骰（包含命運骰）後，30 秒行動倒數會在骰子與棋子動畫期間暫停；落地效果顯示後恢復剩餘時間。若觸發延後的矢量傳送，會等傳送結算後恢復。
- 遊戲頁面會阻止瀏覽器下拉更新及過度滾動手勢；頁面內容仍可在遊戲視窗內上下捲動。

1. 執行 `node serve.mjs`，開啟 <http://127.0.0.1:4173/>；此伺服器只提供靜態檔案。
2. 房主建立房間取得 5 碼房間代碼（不含容易看錯的 0、O、1、I）；其他玩家輸入代碼或掃 QR Code 加入，選擇企業後由房主開始。加入時會顯示「連線中...」，只有收到有效房主握手 ACK 並確認房間狀態正常後才進入大廳。12 秒內未完成連線／握手、房間已滿或版本不相容時，會關閉連線、提示「加入失敗：無法連線至房主或房間不存在」，並保留代碼供重試。
   - 在大廳用按鈕選企業：別人選走的會變灰並寫出是誰選的，同一家只能一個人選（「未定新創集團 🎲」可以多人選，開局時隨機分配）；硬選已被選走的企業會被房主拒絕。
   - 企業名稱旁有圓形棋子色點，點擊可開啟 10 色選色盤。單機準備畫面可改任一位玩家；多人只能改自己的顏色，其他人的按鈕會鎖定。顏色不能重複，房主驗證後透過 PeerJS 同步給全房間，開局後套用到棋子與玩家卡。
   - 大廳會顯示房間 QR Code：其他人用手機相機掃描，會打開遊戲並自動帶入房間代碼，輸入名稱後按「加入房間」即可，不用手打 ID。QR Code 只在線上網址（例如 GitHub Pages）顯示；用 `file://`、`localhost` 或 `127.0.0.1` 開啟時別的裝置打不開，所以不顯示。
   - 大廳設定欄保留至少 320px 的版面空間（窄螢幕會自動改為單欄），進階設定採單欄列表，避免 QR Code 出現時選項標籤被擠成直排。
   - 開始前有人離開（按 ×、關掉頁面）會馬上從大廳移除；手機鎖螢幕或切到別的 App 約 12 秒後顯示「已離線」，回來後自動恢復。房主按開始時，已離線的人不會加入這局（他回來會看到原因）。名字重複會自動加上編號；房間最多 8 人，第 9 人會被告知房間已滿。
   - 等候大廳期間房主離線時會回到加入畫面並填好代碼和名字；對局中斷線則會繼續嘗試重新連線。房主關閉房間時，其他人會看到「房主已關閉房間」。
3. 遊戲資料透過 PeerJS WebRTC DataConnection 在玩家瀏覽器間傳送；PeerJS 訊號服務只負責協助建立連線。PeerJS 使用 `stun.l.google.com:19302`、`stun1.l.google.com:19302`、`stun2.l.google.com:19302` 與 `stun.cloudflare.com:3478`，設定 `iceTransportPolicy: 'all'`、ICE candidate pool size 為 10 與 Unified Plan SDP；DataConnection 使用可靠傳輸與 JSON 序列化，PeerJS debug level 1 會記錄連線階段資訊。程式會監聽底層 ICE 狀態；進入 `connected`／`completed` 時記錄穿透成功；`checking` 時不會在 DataConnection 開啟前嘗試重送握手。狀態變成 `failed` 或 `disconnected` 時會關閉該連線並立即提示「【P2P 網路連線建立失敗，請重新整理網頁後再試】」。目前設定的是 STUN，不含 TURN 中繼；STUN 不保證所有網路環境都能建立 P2P 連線。
   - 大廳玩家列表的房主只顯示一個 👑，並標上「房主」；玩家資訊卡及目前回合提示仍以 👑 標示房主。目前回合的倒數上方會顯示「本回合行動時間：」。房間協定版本已升至 v6；雙方通道開啟時會各自發起握手，房主驗證客機版本後回覆 ACK。請讓所有玩家使用同一版遊戲。
4. 對局狀態由房主統一轉發；互動視窗只會在目前決策者的本機端出現。其他玩家維持純觀戰視角，只看到「等待（玩家名稱）決定中...」，不會顯示對手道具格或可操作面板。拍賣期間僅目前出價者可操作。
5. 結束後開啟結算頁（總資產圖表、生還季數與道具明細表格）。星數排行僅企業之星模式顯示；邪惡企業全員淘汰時副標題為「無人生還」。每位玩家按「確認結果」，全員確認後一起回到同一個等待大廳。
6. 企業之星與首富競爭結束時有專屬結局過場動畫；邪惡企業毀滅日雷射會精準命中被淘汰玩家的棋子，至少播放 0.5 秒後才可開啟結算。

多人對局會在棋盤上方為本機玩家的回合顯示 30 秒倒數，其他回合不顯示；時間到會由房主清除未完成的選擇並結束回合，該玩家看到「行動時間結束」提示，已完成的落地效果保留。所有玩家可在大廳編輯自己的名稱（按 Enter 或點擊輸入欄外送出，開局後鎖定）與自己的棋子顏色；房主可在大廳或玩家卡片企業名稱旁踢出其他玩家。被踢玩家立即回到標題畫面；房主也會封鎖該 Peer ID，不能用同一 Peer ID 再加入。

玩家斷線或停止回應後，房主會先標示離線，並給原 Peer ID 最多 3 分鐘自動重新連線；逾時後會自動移出對局。重新整理頁面會取得新的 Peer ID，不屬於原玩家的自動重連。被移除玩家的進行中資料會清理，已完成的歷史賽季紀錄保留；若只剩一位玩家，該玩家獲勝。單機遊戲不啟用回合計時器、踢人或斷線移除功能。

限制：多人連線使用 PeerJS WebRTC，重新連線與 3 分鐘寬限期受瀏覽器背景分頁暫停、網路和訊號服務影響；房主分頁需保持可運作，離線倒數會在房主分頁恢復執行後繼續檢查。

PeerJS 1.5.2 與 QR Code 產生器（qrcode-generator 1.4.4，以 SRI 驗證）由 unpkg CDN 載入；建立多人連線仍需要網路存取 PeerJS 訊號服務。遊戲及音效的儲存存取遇到瀏覽器封鎖時會捕捉錯誤，但不提供跨重新載入的記憶體存檔替代。靜態頁面可部署至任意 HTTP(S) 主機。

## 存檔

遊戲自動儲存在瀏覽器 `localStorage`。可從頂端匯出 JSON 或匯入舊存檔；存檔保留種子、回合、總資產、星數、能量、道具、神話道具、護盾、子公司、憑證與所有暫時狀態。第 1 版財務模擬存檔可直接匯入並自動遷移。

## 音效

內建程序化 WebAudio 音效，右上角可調整音量或靜音；設定會保存在瀏覽器。賺錢、扣錢、使用技能、弱者領域扣款與魔女因子都有專屬音效；魔女因子另會播放專案內的 `witch_factor.mp3`。

## 開發

- `data.js`：原始企業、道具、棋盤、事件與常數。
- `party_data.js`：新模式、翻新技能、神話道具、特殊格、輪盤與快速決策。
- `engine.js`：原始引擎與擴充掛鉤（8 人、幽靈落地、決策、回合／結算）。
- `party_engine.js`：動態棋盤、通膨、拍賣、投資、查稅、內線、技能、神話道具、毀滅日、驟死賽、結算資料與除錯工具。
- `app.js`、`ui_party.js`、`styles.css`、`party-ext.css`、`index.html`：介面、大廳、動畫、結算與匯出匯入。
- `net.js`：房間、WebRTC、BroadcastChannel 與 HTTP 訊號備援。
- `audio_system.js`：WebAudio 音效管理。
- `serve.mjs`：靜態檔案＋多人訊號伺服器（`PORT`、`HOST` 可覆寫）。
- `game.js`：供直接開啟 HTML 的合併腳本。

修改來源後執行 `node build.mjs`；沒有 Node.js 時可執行 `powershell -ExecutionPolicy Bypass -File .\build.ps1` 更新 `game.js`。規則、派對擴充與同步測試以 `node --test` 執行（`engine.test.js`、`party_engine.test.js`、`sync.test.js`）。

本遊戲的數字與事件僅供娛樂使用，不構成任何投資建議。
